# 금칙어 목록 — 분철 제목·설명·구매처, 닉네임에 쓰면 저장을 막는다(BannedWordFilter).
# 한 줄에 하나. 공백·문장부호를 지우고 소문자로 바꾼 뒤 부분 문자열로 비교한다.
#
# 넣기 전에 확인할 것
# - 분철 글에 흔한 말은 넣지 않는다(섹시·킬링·죽여주는·미쳤다·대박·존잘·먹튀·짝퉁·마약김밥 등).
# - 두 글자 말은 띄어쓰기를 지운 뒤 앞뒤 낱말과 이어져 생기기 쉽다(예: 「2개 새상품」→ 개새, 「날씨 벌써」→ 씨벌,
#   「등 신청」→ 등신, 「또 라이브」→ 또라이, 「짱 개이득」→ 짱개, 「케타(케이타운포유) 민지」→ 케타민).
#   그렇게 생길 수 있으면 빼거나, 생기는 말을 allowed.txt 에 넣는다.
# - 다른 말 속에 들어가는 영어 짧은 말은 넣지 않는다(ass·cum·tit·sex·shit·dick·fuk — class·title·sexy·shitajiki·Dickies·Fukuoka).
